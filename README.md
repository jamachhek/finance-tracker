# Финансы / Moliya — трекер доходов и расходов

Веб-приложение для учёта доходов и расходов в стиле **Liquid Glass**.
Работает прямо в браузере, без сервера и установки: данные хранятся локально (`localStorage`).

Проект состоит всего из трёх файлов: `index.html`, `main.css`, `script.js`.

## Возможности

- **Дашборд**: баланс, доходы, расходы, норма сбережений; графики по месяцам,
  структура по категориям (круговая диаграмма) и динамика баланса.
- **Операции**: добавление, просмотр, редактирование и удаление (CRUD), поиск, фильтры и сортировка.
- **Категории**: собственные категории доходов и расходов с цветами (CRUD).
- **Валюта**: по умолчанию узбекский сум; можно переключить на $, €, ₽, ₸ с настраиваемыми курсами.
- **Языки**: русский и узбекский (латиница), переключатель RU / UZ в правом верхнем углу.
- **Темы**: светлая и тёмная (или как в системе).
- **Данные**: экспорт и импорт в JSON, демо-данные, полный сброс.
- **Анимации**: графики растут при появлении на экране, «жидкие» переходы навигации и переключателей,
  стеклянные выпадающие списки; уважается системная настройка «уменьшить движение».

## Как запустить

Откройте `index.html` в браузере — и всё.
Стеклянные выпадающие списки используют новую возможность CSS (`appearance: base-select`):
в Chrome / Edge они выглядят как задумано, в остальных браузерах остаются обычными системными.

# Moliya — daromad va xarajatlar hisobi

**Liquid Glass** uslubidagi daromad va xarajatlarni hisobga olish ilovasi.
Brauzerda server va o‘rnatishsiz ishlaydi: ma’lumotlar mahalliy saqlanadi (`localStorage`).
Ishga tushirish uchun `index.html` faylini brauzerda oching. Interfeys tili: rus va o‘zbek (RU / UZ).
