# PRD — «Финансы»: трекер доходов и расходов

## 1. Зачем продукт
Людям в Узбекистане (и не только) нужен простой способ видеть, куда уходят деньги. Банковские приложения показывают только свою карту, таблицы — неудобны с телефона. «Финансы» — один экран, где видно баланс, доходы, расходы и их структуру за выбранный период, в сумах по умолчанию.

## 2. Для кого
| Персона | Что хочет | Что важно |
|---|---|---|
| Студент / молодой специалист | понять, на что уходит стипендия или зарплата | быстро добавить трату с телефона |
| Фрилансер | видеть доходы от разных клиентов по месяцам | несколько валют, курс к суму |
| Семья | общий учёт, контроль коммуналки и продуктов | понятные категории, графики |

## 3. Цели и метрики
- Добавление операции — не дольше 10 секунд (2 касания + сумма).
- Пользователь видит баланс и норму сбережений сразу при открытии.
- Удержание: пользователь возвращается хотя бы раз в неделю (D7 ≥ 25%).
- 0 потерь данных при смене устройства (облачная синхронизация).

## 4. Объём (что уже есть — v1)
1. **Дашборд**: баланс, доходы, расходы, норма сбережений; графики «по месяцам» (столбцы), «динамика баланса» (линия), «структура» (кольцевая диаграмма с легендой); последние операции. Период: месяц / 3 / 6 / 12 месяцев / всё время.
2. **Операции (CRUD)**: добавить, изменить, удалить; поиск, фильтр по типу и категории, сортировка.
3. **Категории (CRUD)**: доходные и расходные, свой цвет; 13 стандартных.
4. **Настройки**: валюта (UZS по умолчанию, USD, EUR, RUB, KZT) и курсы к суму; тема (авто / светлая / тёмная); язык RU / UZ; экспорт / импорт / очистка; демо-данные.
5. **Аккаунт**: регистрация (пароль дважды), вход, выход, «Забыли пароль?» с 6-значным кодом на почту, удаление аккаунта с подтверждением паролем.
6. **Политика конфиденциальности** (RU / UZ) — для публикации в Google Play.
7. **Режимы работы**: облачный (Vercel + Neon) и локальный (GitHub Pages, только память браузера).

## 5. Вне объёма v1
- Привязка банковских карт и автоматический импорт платежей.
- Совместный доступ нескольких людей к одному кошельку.
- Бюджеты и лимиты по категориям, напоминания.
- Нативные приложения (будет PWA → TWA для Google Play).

## 6. Дорожная карта
| Версия | Что |
|---|---|
| v1.1 | PWA (manifest, service worker, офлайн), иконки |
| v1.2 | Публикация в Google Play через TWA, свой домен, домен для писем Resend |
| v1.3 | Бюджеты по категориям и предупреждения о превышении |
| v2.0 | Повторяющиеся операции, несколько счетов (наличные / карта) |

## 7. Риски
- Письма с кодом уходят только на почту владельца Resend, пока не подтверждён свой домен.
- Курсы валют вводятся вручную — могут устаревать.
- Данные в облаке хранятся одним JSON на пользователя (лимит 2 МБ) — при росте нужна нормализация.
